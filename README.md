# FOODY Authentication V1

A responsive, single-file front-end prototype for FOODY's login and registration experience.

## Included
- AMOLED-inspired black and white interface
- Login and registration tabs
- Registration fields: country calling code, phone number, email, username, first name, last name, password
- Language selector: English, French, Egyptian Arabic, Spanish, Portuguese
- RTL layout for Arabic
- Password visibility toggle
- Responsive desktop and mobile layout

## Run
Open `index.html` in a modern browser. No build step or dependencies are required.

## Important
This is a front-end prototype only. Authentication, database persistence, Google sign-in, email verification, and SMS/OTP verification are not connected.
